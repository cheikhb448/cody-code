# Cody Code — Fonctionnalités

Cody Code est un éditeur de code basé sur le code open source de VS Code (« Code - OSS », licence MIT), avec une identité visuelle et un assistant IA qui lui sont propres.

**Légende :** ✅ fait et testé · 🚧 en cours · ⬜ à faire

> Ce fichier est mis à jour au fil du projet. Une case n'est cochée ✅ qu'après un test réel.

---

## 1. Éditeur
- ⬜ Édition de texte multi-fichiers avec onglets
- ⬜ Coloration syntaxique
- ⬜ Numéros de ligne, fil d'Ariane (breadcrumbs)
- ⬜ Recherche et remplacement (fichier et dossier, avec expressions régulières)
- ⬜ Multi-curseurs et sélection multiple
- ⬜ Plier / déplier le code
- ⬜ Mini-carte (minimap)
- ⬜ Annuler / rétablir
- ⬜ Éditeur divisé (plusieurs volets côte à côte)
- ⬜ Comparaison de fichiers (diff)
- ⬜ Formatage automatique
- ⬜ Enregistrement automatique

## 2. Intelligence du code
- ⬜ Autocomplétion (IntelliSense)
- ⬜ Aide sur les paramètres de fonction
- ⬜ Aller à la définition / aux références
- ⬜ Renommage intelligent de symboles
- ⬜ Détection d'erreurs et avertissements en direct
- ⬜ Corrections rapides
- ⬜ Extraits de code (snippets)
- ⬜ Prise en charge des langages via le protocole LSP

## 3. Explorateur et navigation
- ⬜ Explorateur de fichiers (créer, renommer, déplacer, supprimer)
- ⬜ Ouverture de dossiers et d'espaces de travail multiples
- ⬜ Recherche globale dans le projet
- ⬜ Accès rapide aux fichiers et à la palette de commandes (Ctrl+P / Ctrl+Shift+P)
- ⬜ Vue Structure (symboles du fichier)
- ⬜ Historique local des fichiers (timeline)

## 4. Terminal intégré
- ⬜ Terminal dans l'éditeur (PowerShell, cmd, bash, zsh)
- ⬜ Plusieurs terminaux, terminal divisé
- ⬜ Liens cliquables dans la sortie

## 5. Contrôle de version (Git)
- ⬜ Vue Git : changements, ajout, commit
- ⬜ Branches (créer, changer, fusionner)
- ⬜ Comparaison visuelle des changements
- ⬜ Résolution de conflits de fusion
- ⬜ Push / pull / clone
- ⬜ Indicateurs de modification dans la marge

## 6. Exécution et débogage
- ⬜ Lancer et déboguer un programme
- ⬜ Points d'arrêt (simples, conditionnels)
- ⬜ Pile d'appels, variables, expressions surveillées
- ⬜ Console de débogage
- ⬜ Configurations de lancement (`launch.json`)
- ⬜ Tâches (`tasks.json`)

## 7. Extensions
- ⬜ Vue Extensions (installer, désactiver, désinstaller)
- ⬜ Magasin d'extensions libre (Open VSX) et autres services similaires
- ⬜ Extensions recommandées par projet
- ⬜ Thèmes d'icônes et de couleurs via extensions

## 8. Personnalisation
- ⬜ Paramètres (interface graphique + `settings.json`)
- ⬜ Raccourcis clavier personnalisables
- ⬜ Thèmes de couleurs (thème sombre Cody par défaut, clair disponible)
- ⬜ Profils d'utilisateur
- ⬜ Synchronisation des paramètres
- ⬜ Langue de l'interface (français inclus)

## 9. Interface Cody (design propre)
- ⬜ Barre de titre avec nom du projet, recherche globale, notifications, compte
- ⬜ Barre d'activités à gauche (Explorateur, Recherche, Git, Exécuter, Extensions)
- ⬜ Explorateur en arbre avec icônes colorées par type de fichier
- ⬜ Onglets de fichiers stylisés
- ⬜ Panneau du bas (Terminal, Problèmes, Sortie, Débogage, Console)
- ⬜ Barre d'état (langage, encodage, fins de ligne, branche Git, état « Prêt »)
- ⬜ Basculement thème clair / sombre en un clic

## 10. Cody Assistant (IA)
- ⬜ Panneau latéral à droite, ouvrable et fermable
- ⬜ Onglets : Assistant · Chat · Codebase · Context
- ⬜ Actions rapides : générer du code, expliquer le code, corriger les erreurs, améliorer le code
- ⬜ Saisie de question avec pièces jointes et images
- ⬜ Aucune donnée envoyée sans accord de l'utilisateur

## 11. Productivité
- ⬜ Emmet (écriture rapide HTML/CSS)
- ⬜ Éditeur de notebooks
- ⬜ Aperçu Markdown
- ⬜ Mode sans distraction (Zen) et plein écran
- ⬜ Espaces de travail de confiance (Workspace Trust)
- ⬜ Développement à distance (SSH, conteneurs, WSL)

## 12. Accessibilité et sécurité
- ⬜ Compatibilité lecteurs d'écran
- ⬜ Contraste élevé
- ⬜ Mode restreint pour dossiers non fiables
- ⬜ Télémétrie désactivée par défaut
- ⬜ Audit de sécurité des dépendances

## 13. Plateformes
- ⬜ Windows
- ⬜ macOS
- ⬜ Linux
- ⬜ Version navigateur (web)
